# AnansiWorkbench — LLM Experimentation Platform

AnansiWorkbench is a standalone, local-first LLM experimentation workbench designed for repeatable, large-scale prompt, model, and parameter testing. It operates completely offline in modern web browsers with local IndexedDB storage and background Web Worker execution.

## Features

- **Local-First Architecture**: No backend server or cloud database required. Runs directly in the browser with IndexedDB persistence.
- **Persistent Web Worker Execution**: Large batch runs execute in a background Web Worker that survives tab navigation and browser refreshes.
- **Credential Isolation**: API keys are stored locally in IndexedDB and are automatically stripped when exporting database backups.
- **Experiment Builder**: Define prompt templates (Personality, Scenario, Initial Message), select multiple models, and set repetition counts.
- **Subtest Builder & Field Overrides**: Create distinct test cases with subtest-level prompt and repetition overrides.
- **Dynamic Test Record Sheets**: Create custom qualitative/quantitative evaluation metrics (checkboxes, dropdowns, ratings, numbers, notes) with experiment-to-subtest field inheritance.
- **Side-by-Side Model Comparison**: Compare responses generated by different models for the exact same stimulus side by side.
- **Searchable Research Archive**: Filter past experiments, runs, and responses by keyword, status, tags, and date range.
- **Data Export & Import**: Full JSON database backup & restore, CSV export for data analysis (Python/Excel/R), and AnansiForge Vault backup import adapter.
- **Local Data Visualization**: Offline HTML5 Canvas chart renderer showing latency distributions, token usage, and custom evaluation metric distributions.

## Getting Started

### Local Development Server

Run the static HTTP server:

```bash
npm start
```

Open your browser to:
`http://127.0.0.1:5500`

### Acceptance Test Suite

To run the automated acceptance test suite (Tests A–J), open your browser's Developer Tools Console (`F12`) on the page and run:

```javascript
await WorkbenchTests.runAllTests();
```

│   ├── export.js        # JSON Backup & CSV Export
│   ├── charts.js        # Canvas Visualization Charts
│   └── import.js        # AnansiForge Vault Import Adapter
└── tests/
    ├── mock-provider.js # Standalone Mock Provider Generator
    └── run-tests.js     # Acceptance Test Suite (Tests A-J)
